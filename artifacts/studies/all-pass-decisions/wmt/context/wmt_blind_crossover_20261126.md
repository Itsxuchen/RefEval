# Applying three audit decisions to first-pass expert translation ratings

## Candidate and feasibility gate, set before opening development ratings

Use the English-to-German news portion of WMT23 documented by Riley et al., ACL 2026, sections 3–4. The three professional translators' Single judgments started without existing annotations. Self, Other and Auto re-annotations showed prior answers. Use only system/document/segment keys from the re-annotation release to identify the studied panel. Exclude human reference translations and all of news_guardian.114893 and news_aj-english.33941 because excluded second-round records from those documents were displayed during schema inspection. The second document was added following a team disclosure before any development outcome was read. Both entire documents are excluded across systems. Confirm the Single membership, not merely the language and benchmark. The research team previously examined WMT22 schema; this WMT23 cohort has not been used for the present study's claims.

Fix Claude Sonnet 4.5 as initial judge and Haiku 4.5 as auxiliary; both from Amazon's published unified-mqm-boosted-v5 source-plus-translation predictions. No human fields cached in either model file enter the study. Select only unambiguous matched source/translation records with usable outputs from both models and exactly three Single vectors. Preserve each distinct system translation as a unit, the original document as a cluster. Exclude a record whose texts or primary/auxiliary predictions cannot be joined unambiguously. Report exclusions and whether identical translations from multiple systems share a cached judgment.

Each translation has four binary checks: absence of a recorded Major or Critical target error in accuracy, fluency, terminology, and remaining target issues (including style, locale, non-translation and unintelligible text). An accuracy omission can be marked in the source and still counts against the translation. Exclude errors attributed solely to the source; use the release's severity convention for whole-segment non-translations (a non-translation at Major severity or above fails the remaining-target check). This all-pass event is a derived release standard. One query retrieves one expert's answer for one of the four categories. It counts information, not minutes of translation work.

Rank eligible source documents by SHA-256 of the UTF-8 string 'refeval-wmt23-first-pass-v1|' + original document identifier. Assign ceil(one third) of documents with lowest hash to development, all others to confirmation. Group every segment/system from the same document together. Before any confirmation outcome is computed, inspect development support only. For each complete reversal direction require at least 20 distinct translations, at least 5 source documents, and at least 10 output equivalents (average the three auditor indicators). Require the same 20 translations and 5 documents for early approvals, counted once if seen in any auditor/order. Project at least 30 distinct held translations per reversal direction by scaling pilot rates by the masked held count. These are prespecified minimum event counts for reporting both directions. A sample of 30 independent events would give a worst-case binomial 95% half-width of about 18 points; actual precision depends on clustering. Make no assertion of statistical power for small policy differences. Report actual held counts and intervals even if sparse. If this pilot fails, record it and do not open this holdout, change this target, or pick a model using the data.

## Fixed estimands and analysis to be sealed after the feasibility check

Errors refer to disagreement with the other professional translator. A false release is a policy PASS scored FAIL and a false rejection is the reverse. Use equal costs (1,1) for the primary analysis for comparability with the two existing panels. Separately report loss 3*FP+FF and FP+3*FF as symmetric decision scenarios; neither ratio estimates financial harm. Report both component rates. Test one primary contrast: adopting the complete audit minus retaining the initial judge, per hundred translations. A paired 95% interval wholly below zero supports improved peer agreement on this panel; wholly above supports harm; crossing zero leaves direction unresolved. Report the fraction of completed reversals a peer endorses in each direction separately and combined.

At 50% of the total number of checks, use the earlier disagreement-first protocol: sort units by document then stable segment/system key; use src.conjunction_policy_study.make_order with release order, disagreement_then_random and seeds 1–31. Query the same positions for all rotations and policies. Eager replaces the judge bits at checked positions and recomputes AND. Gating retains the original verdict until one checked failure or a complete set of passes. An early approval is eager PASS and gated FAIL. Report both absolute losses at half budget. Calculate peer endorsement of early approvals, of all eventual complete upward changes and of the early subset ultimately upheld; follow the SAME early cases to their own complete verdicts. Contrast early minus eventual errors per 100 ALL outputs, holding decisions elsewhere equal. A positive value means a further check could avoid disagreement. A positive difference of early/full conditional endorsement rates alone is not evidence that waiting helped the same cases.

Give each translation equal weight, its three auditors equal weight, and each auditor’s two remaining peers equal weight. Average the 31 fixed query paths. Use 1,999 paired percentile bootstrap draws (NumPy default_rng(20261125), multinomial with replacement, over ascending document keys). Each draw retains all observations/roles/orders for a document and recomputes denominators. Count valid draws for event-conditioned outcomes. These are pointwise composition intervals, conditional on recorded reviewers, systems and masks. Check endpoint policy equality, matched-loss identity and counts against a separately written implementation. Freeze the scheme, source hashes, split, code and development support in a local SHA-256 receipt before opening the held labels. This is a locally timestamped prospective analysis of historical public records; source data, prompt development and foundation-model exposure are outside our control.

## Candidate record

CoNLL-2014 GEC also has independent annotations by two language experts and archived system corrections. It would require an edit-to-check mapping for a new application. Stanford CheXpert releases separate radiologist findings and machine predictions; the documentation describes individual readings, its machine decisions are image findings, and it is further from the language-output audit. The present experiment selects WMT on alignment and explicit first-pass procedure before looking at direction or performance.
