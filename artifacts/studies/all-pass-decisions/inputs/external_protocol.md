# SummEval held-article judge selection

The unit is a system-generated summary of a CNN/Daily Mail article. The source grouping is the original article. Compare the G-Eval GPT-4 judge and the UniEval trained multidimensional evaluator. A summary qualifies only when all four binary dimension thresholds clear. This is a constructed conjunctive interpretation of an ordinal summarization benchmark.

## Frame and split

The archived expert and judge files contain the same 1,600 (doc_id, system_id) keys on 100 articles. Each original expert record has three ratings. The four G-Eval files each have 20 reply slots per key. Preflight used only attachment names, metadata, counts, keys, text matching, file hashes and published prompt ranges. Article order is ascending SHA-256 of the UTF-8 string `summeval-selection-v1|<doc_id>`, with lexical ID as tie-break. Use the first 30 articles for development and the other 70 for one held-article assessment. Dropping an invalid output does not reallocate its article. Report complete-case retention and source clusters. Evaluate the held summaries only after a local digest and a separate development-choice seal.

## Gold target and two judge representations

Order the dimensions as coherence, consistency, fluency and relevance. For each expert-rated dimension, pass when at least two of three experts independently award an integer rating of 4 or 5. Exclude invalid/incomplete expert vectors. The crowd annotators and the derived aggregate in the judge releases play no role. The expert median before dichotomization is retained for a descriptive ordinal association check.

G-Eval uses 20 returned GPT-4 replies per dimension. Follow the original source parser's leading numeric token, optionally prefixed by a space. Reject unparsable or out-of-scale values and require at least 16 valid scores out of the 20 slots for each dimension. Use their arithmetic mean. The coherence, consistency and relevance prompts have range 1–5, with pass threshold 4. The fluency prompt has range 1–3. Use 2.5, the same position three quarters of the way from its minimum to maximum. This item differs from the five-point expert fluency scale. UniEval provides a separate score per dimension with high values favoring an affirmative response to a quality question. Use score >=0.50 on its 0–1 scale. For sentence-scored dimensions this is an aggregate of sentence scores. These are distinct measurement scales and fixed thresholds are not calibrated to the same prevalence.

For one predeclared sensitivity, map the ordinal values of each evaluator/dimension to the expert bits using the development articles only. Candidate thresholds are all unique development score values plus one representable value above their maximum, and the primary thresholds. Classify values greater than or equal to the cutoff as pass. Choose largest empirical dimension-level accuracy. On ties choose the candidate nearest the primary cutoff, then the higher candidate. Apply the same eight cutoffs unchanged to held articles. This comparison quantifies sensitivity to score calibration. Report judge and expert pass rates at both criterion and summary level and dimension-wise Spearman correlations (average ties) with expert median on the held articles. These diagnostics do not affect any selection.

## Decisions and precision

The three development-only selectors are pooled criterion agreement, the empirical cost-weighted task FP/FF loss, and an independent asymmetric-error product based on criterion conditional errors combined with the development rubric composition. Use the concurrently developed shared selector implementation and its shared predetermined tie rule. Equal FP/FF costs are primary. False-pass:false-fail cost ratios of 3:1 and 1:3 are sensitivity analyses. Freeze the choices, counts, and any ties for each cost and representation before scoring or disclosing any held outcomes. Report each candidate individually as well as the chosen candidates, including adverse and null comparisons.

The primary difference is held errors per 100 summaries for the product-selected candidate minus the criterion-agreement-selected candidate at equal costs on the fixed-threshold panel. Report the same contrast against empirical task-loss selection. One fewer error per 100 is the descriptive practical margin. Claim an external selector improvement only if the chosen candidates differ, the upper endpoint of the paired 95% interval lies below zero against criterion agreement, and the estimated reduction is at least one per 100. Identical selected candidates tie by construction. Distinguish an observed tie from statistical equivalence across new domains.

For interval estimation use 1,999 shared bootstrap draws of complete held article groups with replacement and seed 20261125; count all retained summaries of each sampled article, dividing by the number of summaries in the draw. Intervals are percentile, conditional on frozen development choices. Report development and validation cluster counts and practical resolution relative to the observed paired uncertainty. There was no prospective data collection, inference call, global multiplicity adjustment or public preregistration. The previously released public data have been studied by others; only this analysis kept held outcomes masked.
